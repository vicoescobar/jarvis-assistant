# ADHD UX & Prompt Engineering Rules

1. **Zero Friction (< 2 minutes):** Every notification or UI action must be completable in under 2 minutes. Limit morning briefings to 4 lines max.
2. **No Shame / No Streaks:** Never implement red warning badges, broken streak counters, or guilt-inducing copy. Missed tasks are silently moved to a "Parking" list during the 3 AM Night Amnesty.
3. **Implementation Intentions (Gollwitzer):** Frame daily priorities using "Si [Déclencheur concret], alors [Micro-action physique de 2 min]".
4. **Ableton Live Sandbox Rule:** Frame music sessions strictly as 45-minute timed sandboxes (Sound Design OR Arrangement) ending with a mandatory 15-second MP3 export ritual (Peak-End Rule).
