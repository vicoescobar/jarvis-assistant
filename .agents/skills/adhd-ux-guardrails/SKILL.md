# ADHD UX & Prompt Engineering Rules

1. **Zero Friction (< 2 minutes):** Every notification or UI action must be completable in under 2 minutes. Limit morning briefings to 4-5 well-spaced sections max.
2. **No Shame / No Streaks (No Night Amnesty):** Never implement red warning badges, broken streak counters, or guilt-inducing copy. Do NOT move, archive, or delete unfinished tasks from Google Tasks (`@default`) via automated night rollovers; tasks stay untouched in the main list and are read without shaming.
3. **Implementation Intentions (Gollwitzer):** Frame daily priorities using "Si [Déclencheur concret], alors [Micro-action physique de < 2 min]".
4. **Ableton Live Sandbox Rule:** Frame music sessions strictly as 45-minute timed sandboxes (Sound Design OR Arrangement) ending with a mandatory 15-second MP3 export ritual (Peak-End Rule).
